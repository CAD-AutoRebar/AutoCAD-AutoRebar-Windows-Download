## 🧠 Overview

**AutoRebar** brings reinforcement-focused functionality directly into the AutoCAD environment, providing tools for developing detailed rebar layouts for reinforced-concrete structures. Its dedicated workflow allows structural professionals to define reinforcement geometry, manage bar information, and prepare organized drawings while continuing to work within a familiar CAD interface.

The add-on provides a structured approach to reinforcement placement and documentation, with support for multiple bar shapes, marks, spacing, dimensions, and related annotations. Drawing information can be connected and organized so that reinforcement details remain easier to manage as layouts are adjusted, expanded, or refined throughout a project.

**AutoRebar** is suitable for detailing applications involving concrete walls, slabs, foundations, columns, retaining structures, and other reinforced elements. Scheduling, quantity information, configurable measurement systems, and export capabilities extend the workflow beyond basic drafting and help users prepare more complete reinforcement documentation.

## 🚀 Key Features

| Feature | Description |
|----------|-------------|
| 🏗️ **Reinforcement Layouts** | Develop detailed rebar arrangements using dedicated objects within the AutoCAD workspace. |
| 📐 **Multiple Bar Shapes** | Work with a variety of straight, bent, curved, hooked, and loop-style reinforcement forms. |
| 🔗 **Linked Detailing Data** | Associate reinforcement geometry with marks, dimensions, spacing, and supporting drawing information. |
| 🏷️ **Bar Identification** | Assign organized marks and descriptive information to reinforcement groups and individual elements. |
| 📋 **Schedule Generation** | Compile reinforcement information into structured bar bending schedules for project documentation. |
| 📊 **Rebar Quantities** | Extract useful quantity information from the reinforcement data contained within drawings. |
| 📤 **Spreadsheet Export** | Export schedule-related information for further processing and documentation in spreadsheet applications. |
| ⚙️ **Configurable Workflow** | Adjust units, annotations, marks, and schedule presentation to suit different detailing requirements. |

## Additional Information for Windows Users

AutoRebar is designed to make reinforcement drafting more structured by introducing specialized rebar objects and detailing controls into AutoCAD. Instead of relying exclusively on manually drawn geometry, users can work with dedicated reinforcement elements containing information relevant to structural detailing.

The relationship between bars and their associated documentation is an important part of the workflow. Marks, dimensions, spacing values, and other annotations can be coordinated with reinforcement elements, helping users keep drawings organized when changes are made to a structural layout.

For projects requiring detailed reinforcement documentation, **AutoRebar** combines geometry creation, bar organization, scheduling, and quantity-related functionality in one CAD-based workflow. These capabilities can be used across different reinforced-concrete applications while supporting both metric and imperial project configurations.
